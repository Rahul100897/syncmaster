# SyncMaster
Shopify multi-store product and inventory sync app.
Embedded inside Shopify Admin — no external dashboard.

## Quick start
1. npm install
2. cp .env.example .env (fill in all values)
3. npx prisma migrate dev
4. Terminal 1: shopify app dev
5. Terminal 2: npm run worker
